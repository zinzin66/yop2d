## What is Yop2D?

- **100% free, never any ads.**
- **No code:** the game logic is built with visual nodes linked together (127 ready-to-use nodes).
- **Works offline**, on Android 7 and later, on tablets and phones (landscape).
- **Export your game as an APK** directly on your device: no computer, no server.
- **Your games belong to you:** give them away or sell them, with **no Yop2D logo or watermark**.
- Physics, tiles, animations, particles and screen effects, sounds and music, camera, dialogue in several languages, inventory, save games…
- Interface, help and guides in 9 languages: English, French, Spanish, German, Italian, Portuguese, Russian, Simplified Chinese and Japanese.
- 5 example games included: Neon shooter, Neon jump, Lost on the moon, an effects showcase and a parallax scene.

➡️ Everything else — node reference, beginner guides, FAQ, comparison with other engines — is on the **[official website](https://zinzin66.github.io/Yop2d-web/)**.

## Download and updates

The latest version is always in **[Releases](https://github.com/zinzin66/yop2d/releases/latest)** (file `Yop2D.apk`), and on [itch.io](https://yop2d-dev.itch.io/yop2d-no-code-game-engine).
Yop2D can check for updates by itself from its home screen.

When installing the APK, Android may show a warning because the app does not come from the Play Store: this is normal for any app downloaded from a website.

## About this repository

This repository only contains the **published versions** of Yop2D.
The engine is free to download and use, but **its source code is not public**: copying, modifying, redistributing or selling the engine is not allowed. The games you create with Yop2D are yours.

Found a bug or have an idea? Come and talk about it on [Discord](https://discord.gg/nHqCcqHZNQ).

Yop2D is made by an independent developer.

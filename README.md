Yop2D (formerly Ludexa) is a standalone 2D game engine built in native Java for Android. It lets anyone create complete 2D games directly on an Android tablet or phone, without writing a single line of code and without a PC. When your game is ready, Yop2D exports it as a standalone APK, 100% offline.

## ✨ Features

* **No-code visual nodes:** build your game logic with over 90 descriptive nodes connected together (movement, physics, animations, sound, dialogues, inventory, camera, timers, conditions, functions…).
* **On-device APK export:** one button turns your project into a standalone `.apk`. Everything is processed locally: no server, no cloud, no PC.
* **Tilemap editor:** import a tileset, paint your levels tile by tile, and mark solid tiles once. Collisions are automatic.
* **Prefabs (scene as object):** any scene can be placed as an object inside another scene.
* **Tag targeting:** a single node can act on every object sharing the same tag.
* **Simple formulas:** use variables, finger position, joystick, time and object properties anywhere (e.g. `=score + 1`).
* **Physics & behaviors:** gravity, bouncing, impulses, collisions, ground detection, chase and flee.
* **Touch controls:** virtual joysticks, buttons, HUD overlays and multi-touch (move and jump at the same time).
* **Pause & slow motion:** the whole game (movement, animations, fades, timers) follows pause and slow motion.
* **Animation editor:** preview your 2D animations in real time inside the engine.
* **Styled titles:** gradients, outlines, neon, shadows and more, rendered natively for lighter games.
* **Touch-friendly editor:** tap to select, drag to scroll, hide or lock objects in one tap.
* **Tablets and phones:** most comfortable on tablets, and usable on phones in landscape with a compact layout.
* **9 languages:** English, French, Spanish, Portuguese, Russian, German, Italian, Simplified Chinese and Japanese.
* **Example games included.**

## 🛠 Why Yop2D?

Most mobile game engines are companions to desktop software. With Yop2D, the whole process happens on your Android device: designing levels, building game logic, and exporting the final APK. If classic engines feel hard to use on a touchscreen, Yop2D is designed for you.

## 📊 Privacy

Yop2D sends one anonymous statistic when it opens (app version, Android version, device language) to count how many people use it. No personal data, nothing from your projects. It can be turned off on the home screen. Games exported with Yop2D send nothing.

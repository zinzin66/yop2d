================================================
  OFFIZIELLE YOP2D-DOKUMENTATION - BLUEPRINT
================================================

Diese Dokumentation verwendet ein visuelles Format, um dir zu helfen, wie du deine Blöcke (Knoten) verbindest.
( ) = Was du konfigurieren oder als Eingang verbinden musst.
[ ] = Der Block selbst.
---> = Die Richtung der Aktion (der Programmablauf).

--- EREIGNISSE ---

=========================================
[ Beim Start ]
=========================================
        (Start) ---> [ Ausführen ] --->

* FUNKTION: Wird automatisch und nur einmal ausgeführt, sobald die Szene auf dem Bildschirm geladen ist.
* BEISPIEL: Feinde an ihrer Startposition platzieren oder die Spielergesundheit auf 100 setzen.

=========================================
[ Jeden Frame ]
=========================================
      (Schleife) ---> [ Ausführen ] --->

* FUNKTION: Wird kontinuierlich ausgeführt, bei jeder Bildschirmaktualisierung (Framerate).
* BEISPIEL: Ein Objekt endlos um sich selbst drehen lassen oder einen Punktestand aktualisieren.

=========================================
[ Bei Klick auf Objekt ]
=========================================
          (Ziel) ---> [ Klick! ] ---> (Ausführen)

* FUNKTION: Wird ausgelöst, wenn der Finger des Spielers das Zielobjekt berührt.
* BEISPIEL: Eine Truhe öffnen, eine Schaltfläche auslösen oder einen Dialog starten.

=========================================
[ Klick-Ende ]
=========================================
    (Bildschirm) ---> [ Losgelassen ] ---> (Ausführen)

* FUNKTION: Wird ausgelöst, wenn der Spieler seinen Finger vom Bildschirm nimmt, egal wo.
* BEISPIEL: Das Schießen stoppen, wenn der Finger angehoben wird.

=========================================
[ Ziehen Start / Ende ]
=========================================
        (Objekt) ---> [ Ziehen ] ---> (Ausführen)

* FUNKTION: Wird in dem Moment ausgelöst, in dem der Spieler beginnt, ein bewegliches Objekt zu ziehen, und wenn er es loslässt.
* BEISPIEL: Einen Schlüssel auf eine Tür fallen lassen, um sie zu öffnen.

=========================================
[ Kollision A/B ]
=========================================
      (Objekt A) ---> [              ]
      (Objekt B) ---> [ Kollision!   ] ---> (Ausführen)

* FUNKTION: Wird genau in dem Moment ausgelöst, in dem Objekt A in physischen Kontakt mit Objekt B kommt.
* BEISPIEL: Wenn "Spieler" "Münze" berührt -> Einen Ton abspielen und die Münze zerstören.

=========================================
[ Wenn Objekt Tag berührt ]
=========================================
        (Objekt) ---> [              ]
      (Tag-Text) ---> [ Kollision!   ] ---> (Ausführen)

* FUNKTION: Wird genau in dem Moment ausgelöst, in dem das Zielobjekt mit einem beliebigen Objekt kollidiert, das den angegebenen Tag trägt.
* BEISPIEL: Wenn "Rakete" ein Objekt mit dem Tag "Feind" berührt -> Explosion.

=========================================
[ Zone betreten / verlassen ]
=========================================
      (Objekt A) ---> [              ]
        (Zone B) ---> [ Durchgang    ] ---> (Ausführen)

* FUNKTION: Wird aktiviert, wenn ein Objekt eine definierte Zone betritt oder verlässt (Ideal für unsichtbare Auslöser).
* BEISPIEL: Der Spieler betritt die Zone "Falle" -> Stacheln kommen aus dem Boden.

=========================================
[ Beim Darüberfahren / Ende ]
=========================================
          (Ziel) ---> [ Schweben ] ---> (Ausführen)

* FUNKTION: Behandelt das Bewegen eines Fingers oder Zeigers über ein Objekt, ohne dass geklickt werden muss.
* BEISPIEL: Eine Schaltfläche hervorheben, wenn man darüberfährt.

=========================================
[ Bei Aufprall (Physik) ]
=========================================
        (Objekt) ---> [ Aufprall! ] ---> (Ausführen)

* FUNKTION: Erkennt, wenn das Objekt bei aktivierter Schwerkraft abprallt oder auf ein festes Element trifft.
* BEISPIEL: Ein Steingeräusch erzeugen, wenn ein Fels zu Boden fällt.

=========================================
[ Wenn Variable sich ändert ]
=========================================
      (Variable) ---> [ Änderung ] ---> (Ausführen)

* FUNKTION: Überwacht kontinuierlich eine Variable. Sobald sich ihr Wert ändert, führt dieser Knoten die Sequenz aus.
* BEISPIEL: Wenn sich die Gesundheit ändert, wird der visuelle Gesundheitsbalken aktualisiert.

=========================================
[ Lokales Ereignis ]
=========================================
(Ereignis-Name) ---> [ Empfang ] ---> (Ausführen)

* FUNKTION: Ein benutzerdefiniertes Ereignis, das du über den Knoten "Lokales Ereignis aufrufen" fernauslösen kannst.
* BEISPIEL: "Game Over"-Logik gruppieren, um sie von mehreren Orten aufzurufen.

=========================================
[ Bei Aktionsklick (Abenteuer) ]
=========================================
        (Button) ---> [ Aktion! ] ---> (Ausführen)

* FUNKTION: Wird speziell ausgelöst, wenn die virtuelle "AKTION"-Schaltfläche der Benutzeroberfläche gedrückt wird.
* BEISPIEL: Mit einem NPC sprechen oder ein Schild lesen.


--- BEWEGUNGEN & KI ---

=========================================
[ Kontinuierlich vorrücken ]
=========================================
 (Geschwindigkeit) ---> [ Vorrücken ] ---> 

* FUNKTION: Wendet eine konstante Geschwindigkeit an. Das Objekt bewegt sich automatisch in Richtung seines Rotationswinkels.
* BEISPIEL: Ein geradeaus abgefeuertes Projektil oder ein fahrendes Auto.

=========================================
[ Objekt verfolgen / fliehen ]
=========================================
          (Ziel) ---> [ Folgen/Fliehen ] ---> 

* FUNKTION: Bewegt Objekt A automatisch auf Objekt B zu (oder von ihm weg).
* BEISPIEL: Eine zielsuchende Rakete oder ein Geist, der dem Spieler folgt.

=========================================
[ Bewegungen stoppen / Anhalten ]
=========================================
        (Objekt) ---> [ Stopp ] ---> 

* FUNKTION: Bricht sofort alle Befehle zum Verfolgen, Fliehen oder kontinuierlichen Bewegen eines Objekts ab.
* BEISPIEL: Einen Feind einfrieren, wenn er von einem Eiszauber getroffen wird.


--- RÄUMLICHE LOGIK ---

=========================================
[ Abstand zwischen A und B ]
=========================================
      (Objekt A) ---> [              ] ---> (Wahr)
      (Objekt B) ---> [   Abstand    ]
     (Bedingung) ---> [              ] ---> (Falsch)

* FUNKTION: Berechnet den Abstand in Pixeln zwischen Objekt A und Objekt B.
* BEISPIEL: Prüfen, ob der Spieler nah genug ist, um eine Tür zu öffnen.

=========================================
[ Ausrichten auf (Look At) ]
=========================================
          (Ziel) ---> [ Ausrichten ] ---> 

* FUNKTION: Dreht Objekt A so, dass es Objekt B ansieht.
* BEISPIEL: Ein Verteidigungsturm, der auf den Spieler zielt.

=========================================
[ Nächstes Objekt / Zufall ]
=========================================
           (Tag) ---> [ Suchen ] ---> (In Variable speichern)

* FUNKTION: Findet das nächstgelegene Objekt oder ein zufälliges Objekt zur späteren Verwendung.
* BEISPIEL: Automatisch den nächsten Feind anvisieren.


--- LOGIK & BEDINGUNGEN ---

=========================================
[ Bedingung (Variable) ]
=========================================
      (Variable) ---> [              ] ---> (Wahr)
     (Vergleich) ---> [  Bedingung   ]
          (Wert) ---> [              ] ---> (Falsch)

* FUNKTION: Vergleicht den Wert einer Variablen mit einer Zahl oder einem Text.
* BEISPIEL: Wenn (Punkte > 10) dann (Nächstes Level) sonst (Nichts).

=========================================
[ Wenn Objekt A Zone B berührt ]
=========================================
      (Objekt A) ---> [              ] ---> (Wahr)
        (Zone B) ---> [Überlappung?]
                      [              ] ---> (Falsch)

* FUNKTION: Prüft sofort, ob sich zwei Objekte genau in diesem Moment überschneiden.

=========================================
[ Doppelbedingung (UND/ODER) ]
=========================================
    (Bedingung1) ---> [              ] ---> (Wahr)
      (UND/ODER) ---> [   Doppelt?   ]
    (Bedingung2) ---> [              ] ---> (Falsch)

* FUNKTION: Ermöglicht die gleichzeitige Überprüfung von zwei Bedingungen.
* BEISPIEL: Wenn (Spieler auf dem Boden) UND (Sprungtaste gedrückt) -> Springen.

=========================================
[ Wenn Objekt sichtbar / Wenn Tag ]
=========================================
        (Objekt) ---> [ Prüfen ] ---> (Wahr / Falsch)

* FUNKTION: Prüft, ob sich das Objekt auf dem Bildschirm befindet oder ob es den angeforderten Tag hat.

=========================================
[ Funktion aufrufen ]
=========================================
     (Dateiname) ---> [ Funktion ] ---> 

* FUNKTION: Führt ein externes Blueprint aus, das im Ordner "functions" gespeichert ist.
* BEISPIEL: Eine wiederverwendbare "SpawnMonsters"-Funktion für alle deine Level erstellen.

=========================================
[ Sequenz ]
=========================================
       (Eingang) ---> [ Sequenz ] ---> (Zweig 1)
                      [         ] ---> (Zweig 2)

* FUNÇÃO: Teilt die Ausführung in mehrere Zweige auf, um die Logik deines Blueprints zu strukturieren.

=========================================
[ Cooldown (Abklingzeit) ]
=========================================
         (Dauer) ---> [ Cooldown ] ---> (Ausführung erlaubt)

* FUNKTION: Blockiert vorübergehend die Ausführung der folgenden Knoten für eine definierte Zeit.
* BEISPIEL: Die Feuerrate begrenzen (1 Sek. zwischen jeder Kugel warten).

=========================================
[ Andere Prüfungen... ]
=========================================
(Wenn Joystick Aktiv) | (Wenn in Bewegung) | (Wenn Taste gedrückt) | (Wenn außerhalb des Bildschirms)
* FUNKTION: Schnelle Testblöcke mit Ausgängen (Wahr / Falsch) je nach aktuellem Status.


--- SZENE & HUD ---

=========================================
[ Szene wechseln / neu laden ]
=========================================
    (Szenenname) ---> [ Wechseln ] ---> 

* FUNKTION: Lädt einen neuen Raum / ein neues Level. Die aktuelle Szene wird gespeichert.

=========================================
[ Szene instanziieren / schließen ]
=========================================
    (Szenenname) ---> [ Instanz ] ---> 

* FUNKTION: Lädt ein Prefab oder ein Element (wie ein Popup) innerhalb der aktuellen Szene.

=========================================
[ Kamera fixieren ]
=========================================
        (Objekt) ---> [ Folgen ] ---> 

* FUNKTION: Verbindet die Kamera mit dem Zielobjekt, um ihm automatisch zu folgen.

=========================================
[ Kamerawackeln / Elastizität ]
=========================================
         (Stärke) ---> [ Wackeln ] ---> 

* FUNKTION: Erschüttert den Bildschirm oder ändert die Fließfähigkeit der Kameraverfolgung.
* BEISPIEL: Ein starkes Wackeln bei einer Explosion.


--- AUSSEHEN & OBJEKTE ---

=========================================
[ Objekt bewegen / schieben ]
=========================================
   (Koordinaten) ---> [ Bewegen ] ---> 

* FUNKTION: Teleportiert oder schiebt das Objekt an neue X- und Y-Koordinaten.

=========================================
[ Klon erzeugen (Spawner) ]
=========================================
        (Modell) ---> [ Spawnen ] ---> 

* FUNKTION: Klont das angeforderte Modell und lässt es erscheinen. Verfügbar als an ein Ziel gebunden oder durch feste Position (X, Y).

=========================================
[ Schießen ]
=========================================
      (Projektil) ---> [ Schießen ] ---> 
         (Winkel) --->

* FUNKTION: Erzeugt sofort ein Objekt vom Ziel in eine Richtung und treibt es an.

=========================================
[ Zerstören / Zerstören nach Tag ]
=========================================
        (Objekt) ---> [ Zerstören ] ---> 

* FUNKTION: Löscht das Objekt oder alle Objekte mit einem Tag dauerhaft aus der Szene.

=========================================
[ Fortschritt ändern ]
=========================================
          (Wert) ---> [ Balken ] ---> 

* FUNKTION: Aktualisiert die visuelle Füllung eines Fortschrittsbalkens (z. B. Gesundheitsbalken).

=========================================
[ Anzeigemodus & Filter ]
=========================================
* FUNKTION: Gruppiert die Knoten [Z-Order ändern], [Bild ändern], [Farbfilter], [Deckkraft] und [Mischmodus], um das Aussehen deiner Sprites zu ändern.

=========================================
[ Bildschirmverhalten ]
=========================================
* FUNKTION: Die Knoten [Im Bildschirm halten] (unsichtbare Wand) und [Bildschirm durchqueren] (Pac-Man-Effekt) zur Steuerung der Spielgrenzen.


--- TEXTE & DIALOGE ---

=========================================
[ Text ändern / hinzufügen ]
=========================================
          (Text) ---> [ Schreiben ] ---> 

* FUNKTION: Ersetzt vollständig ein vorhandenes Textobjekt oder fügt Wörter an das Ende an.

=========================================
[ Dialog anzeigen ]
=========================================
   (Wörterbuch-Key) ---> [ Dialog ] ---> 

* FUNKTION: Liest einen Satz aus der Dialogdatei und zeigt ihn auf dem Bildschirm an.


--- VARIABLEN & INVENTAR ---

=========================================
[ Variable ändern / hinzufügen ]
=========================================
          (Wert) ---> [ Mathe ] ---> (Aktualisierte Variable)

* FUNKTION: Ersetzt oder addiert einen Wert (oder eine Berechnung) zu einer Variablen.

=========================================
[ Inventarverwaltung ]
=========================================
(Zum Inventar hinzufügen) | (Entfernen) | (Wenn im Inventar) | (Kombination)
* FUNKTION: Verwaltet die Liste der Gegenstände des Spielers und deren Interaktionen.


--- ZEIT ---

=========================================
[ Warten (ms) ]
=========================================
          (Zeit) ---> [ Pause ] ---> (Nächste Aktion)

* FUNKTION: Pausiert, bevor die Ausführung der folgenden Knoten fortgesetzt wird.


--- AUDIO ---

=========================================
[ Ton / Musik abspielen ]
=========================================
      (mp3-Datei) ---> [ Abspielen ] ---> 

* FUNKTION: Spielt einen kurzen Soundeffekt ab (kann überlappen) oder startet einen langen Hintergrund-Audiotrack.


--- ANIMATIONEN ---

=========================================
[ Animation starten / stoppen ]
=========================================
     (Anim-Name) ---> [ Starten ] ---> 

* FUNKTION: Startet eine vordefinierte Bildsequenz (Sprite-Animation) auf dem Objekt oder stoppt sie.

=========================================
[ Gleiten nach ]
=========================================
           (X,Y) ---> [ Bewegung ] ---> 
         (Dauer) ---> 

* FUNKTION: Bewegt das Objekt reibungslos an neue Koordinaten (Tween).


--- PHYSIK ---

=========================================
[ Impuls / Kraft anwenden ]
=========================================
         (Kraft) ---> [ Schieben ] ---> 

* FUNKTION: Übt eine Kraft auf ein Objekt aus, das der terrestrischen Schwerkraft der Engine unterliegt.

=========================================
[ Geschwindigkeit festlegen ]
=========================================
(Geschwindigkeit) ---> [ Festlegen ] ---> 

* FUNKTION: Erzwingt eine augenblickliche Bewegungsgeschwindigkeit für ein physisches Objekt.

=========================================
[ Boden-Bedingung ]
=========================================
        (Objekt) ---> [ Am Boden? ] ---> (Wahr / Falsch)

* FUNKTION: Prüft, ob das der Schwerkraft ausgesetzte Objekt gerade auf einer festen Oberfläche ruht (unerlässlich, um Springen zu ermöglichen).

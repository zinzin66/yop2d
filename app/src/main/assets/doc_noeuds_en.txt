================================================
  YOP2D OFFICIAL DOCUMENTATION - BLUEPRINT
================================================

This documentation uses a visual format to help you understand how to connect your blocks (nodes).
( ) = What you need to configure or connect as input.
[ ] = The block itself.
---> = The direction of the action (the flow of the program).

--- EVENTS ---

=========================================
[ On Start ]
=========================================
       (Start) ---> [ Execute ] --->

* ROLE: Executes automatically and only once as soon as the scene is loaded on screen.
* EXAMPLE: Place enemies at their starting position, or initialize player health to 100.

=========================================
[ Every Frame ]
=========================================
      (Loop) ---> [ Execute ] --->

* ROLE: Executes continuously, at every screen refresh (framerate).
* EXAMPLE: Make an object rotate infinitely, or update a score.

=========================================
[ On Click on Object ]
=========================================
       (Target) ---> [ Click ! ] ---> (Execute)

* ROLE: Triggers when the player's finger touches the targeted Object.
* EXAMPLE: Open a chest, trigger a button, or start a dialogue.

=========================================
[ On Click End ]
=========================================
       (Screen) ---> [ Released ] ---> (Execute)

* ROLE: Triggers when the player releases their finger from the screen, anywhere.
* EXAMPLE: Stop firing a weapon when the finger is lifted.

=========================================
[ Drag Start / End ]
=========================================
       (Object) ---> [ Drag ] ---> (Execute)

* ROLE: Triggers when the player starts dragging a movable object, and when they release it.
* EXAMPLE: Drop a key onto a door to open it.

=========================================
[ Collision A/B ]
=========================================
     (Object A) ---> [            ]
     (Object B) ---> [ Collision! ] ---> (Execute)

* ROLE: Triggers at the exact moment Object A comes into physical contact with Object B.
* EXAMPLE: When "Player" touches "Coin" -> Play a sound and destroy the coin.

=========================================
[ If Object Touches Tag ]
=========================================
       (Object) ---> [            ]
     (Tag Text) ---> [ Collision! ] ---> (Execute)

* ROLE: Triggers at the exact moment the targeted object collides with any object bearing the indicated Tag.
* EXAMPLE: When "Missile" touches an object with the "Enemy" tag -> Explosion.

=========================================
[ Area Enter / Exit ]
=========================================
     (Object A) ---> [            ]
       (Area B) ---> [ Passage  ] ---> (Execute)

* ROLE: Activates when an object enters or exits a defined area (Ideal for invisible triggers).
* EXAMPLE: The player enters the "Trap" area -> Spikes emerge from the ground.

=========================================
[ On Hover / End Hover ]
=========================================
       (Target) ---> [ Hover ] ---> (Execute)

* ROLE: Handles a finger or pointer hovering over an object, without needing to click.
* EXAMPLE: Highlight a button when passing over it.

=========================================
[ On Impact (Physics) ]
=========================================
       (Object) ---> [ Impact ! ] ---> (Execute)

* ROLE: Detects when the object bounces or hits a solid element while gravity is enabled.
* EXAMPLE: Play a rock sound when a stone falls to the ground.

=========================================
[ When Variable Changes ]
=========================================
    (Variable) ---> [ Change ] ---> (Execute)

* ROLE: Continuously monitors a Variable. As soon as its value is modified, this node runs the sequence.
* EXAMPLE: If health changes, update the visual health bar.

=========================================
[ Local Event ]
=========================================
  (Event Name) ---> [ Receive ] ---> (Execute)

* ROLE: A custom event that you can trigger remotely using the "Call Local Event" node.
* EXAMPLE: Group "Game Over" logic together to call it from multiple places.

=========================================
[ On Action Click (Adventure) ]
=========================================
      (Button) ---> [ Action ! ] ---> (Execute)

* ROLE: Triggers specifically when the virtual "ACTION" button on the interface is pressed.
* EXAMPLE: Talk to an NPC or read a sign in front of you.


--- MOVEMENTS & AI ---

=========================================
[ Move Continuously ]
=========================================
   (Speed) ---> [ Move forward ] ---> 

* ROLE: Applies a constant velocity. The object will move automatically in the direction of its Rotation Angle.
* EXAMPLE: A projectile shot straight ahead, or a driving car.

=========================================
[ Pursue / Flee Object ]
=========================================
  (Target) ---> [ Follow/Flee ] ---> 

* ROLE: Automatically moves Object A towards (or away from) Object B.
* EXAMPLE: A homing missile, or a ghost following the player.

=========================================
[ Stop Movements / Stop ]
=========================================
  (Object) ---> [ Stop ] ---> 

* ROLE: Instantly cancels all pursue, flee, or continuous movement commands on an object.
* EXAMPLE: Freeze an enemy when hit by an ice spell.


--- SPATIAL LOGIC ---

=========================================
[ Distance between A and B ]
=========================================
    (Object A) ---> [            ] ---> (True)
    (Object B) ---> [  Distance  ]
   (Condition) ---> [            ] ---> (False)

* ROLE: Calculates the distance in pixels between Object A and Object B.
* EXAMPLE: Check if the player is close enough to open a door.

=========================================
[ Look At ]
=========================================
      (Target) ---> [ Orient ] ---> 

* ROLE: Rotates Object A so that it faces Object B.
* EXAMPLE: A defense turret aiming at the player.

=========================================
[ Closest Object / Random ]
=========================================
         (Tag) ---> [ Search ] ---> (Save to Variable)

* ROLE: Locates the closest object or a random object to use it afterward.
* EXAMPLE: Automatically target the nearest enemy.


--- LOGIC & CONDITIONS ---

=========================================
[ Condition (Variable) ]
=========================================
    (Variable) ---> [            ] ---> (True)
  (Comparator) ---> [ Condition  ]
       (Value) ---> [            ] ---> (False)

* ROLE: Compares the value of a Variable with a number or text.
* EXAMPLE: If (Score > 10) then (Next Level) else (Nothing).

=========================================
[ If Object A touches Area B ]
=========================================
    (Object A) ---> [            ] ---> (True)
      (Area B) ---> [ Overlaps?  ]
                    [            ] ---> (False)

* ROLE: Instantly checks if two objects overlap at this exact moment.

=========================================
[ Double Condition (AND/OR) ]
=========================================
 (Condition1) ---> [            ] ---> (True)
    (AND / OR) ---> [  Double ?  ]
 (Condition2) ---> [            ] ---> (False)

* ROLE: Allows checking two conditions at the same time.
* EXAMPLE: If (Player grounded) AND (Jump button pressed) -> Jump.

=========================================
[ If Object Visible / If Tag ]
=========================================
      (Object) ---> [ Check ] ---> (True / False)

* ROLE: Checks if the object is on screen, or if it has the requested Tag.

=========================================
[ Call Function ]
=========================================
   (File Name) ---> [ Function ] ---> 

* ROLE: Executes an external Blueprint saved in the "functions" folder.
* EXAMPLE: Create a reusable "SpawnMonsters" function across all your levels.

=========================================
[ Sequence ]
=========================================
       (Input) ---> [ Sequence ] ---> (Branch 1)
                    [          ] ---> (Branch 2)

* ROLE: Divides execution into multiple branches to structure and organize your Blueprint logic.

=========================================
[ Cooldown ]
=========================================
    (Duration) ---> [ Cooldown ] ---> (Execution allowed)

* ROLE: Temporarily blocks the execution of the following Blueprint nodes for a defined delay.
* EXAMPLE: Limit firing rate (wait 1 sec between each bullet).

=========================================
[ Other checks... ]
=========================================
(If Joystick Active) | (If Moving) | (If Button Held) | (If Off Screen)
* ROLE: Quick test blocks with outputs (True / False) depending on the current state.


--- SCENE & HUD ---

=========================================
[ Change / Reload Scene ]
=========================================
  (Scene Name) ---> [ Change ] ---> 

* ROLE: Loads a new room/level. The current scene is saved.

=========================================
[ Instantiate / Close Scene ]
=========================================
  (Scene Name) ---> [ Instance ] ---> 

* ROLE: Loads a Prefab or an element (like a popup) inside the current scene.

=========================================
[ Fix Camera ]
=========================================
      (Object) ---> [ Follow ] ---> 

* ROLE: Attaches the camera to the targeted Object to follow it automatically.

=========================================
[ Camera Shake / Elasticity ]
=========================================
       (Power) ---> [ Shake ] ---> 

* ROLE: Shakes the screen or modifies the camera's tracking smoothness.
* EXAMPLE: A heavy shake during an explosion.


--- APPEARANCE & OBJECTS ---

=========================================
[ Move / Push Object ]
=========================================
 (Coordinates) ---> [ Move ] ---> 

* ROLE: Teleports or pushes the object to new X and Y coordinates.

=========================================
[ Spawn Clone (Spawner) ]
=========================================
       (Model) ---> [ Spawn ] ---> 

* ROLE: Clones the requested Model object and makes it appear. Available as attached to a Target or by fixed Position (X, Y).

=========================================
[ Shoot ]
=========================================
  (Projectile) ---> [ Shoot ] ---> 
       (Angle) --->

* ROLE: Instantly generates and propels an object from the target in a given direction.

=========================================
[ Destroy / Destroy by Tag ]
=========================================
      (Object) ---> [ Destroy ] ---> 

* ROLE: Permanently deletes the object or all objects with a specific Tag from the scene.

=========================================
[ Modify Progress ]
=========================================
       (Value) ---> [ Gauge ] ---> 

* ROLE: Updates the visual fill of a progress bar (e.g., health bar).

=========================================
[ Display Mode & Filters ]
=========================================
* ROLE: Groups the [Change Z-Order], [Change Image], [Color Filter], [Opacity], and [Blend Mode] nodes to modify the visual appearance of your sprites.

=========================================
[ Screen Behaviors ]
=========================================
* ROLE: The [Keep on screen] (invisible wall) and [Wrap around screen] (Pac-Man effect) nodes to control game boundaries.


--- TEXTS & DIALOGUES ---

=========================================
[ Modify / Append Text ]
=========================================
        (Text) ---> [ Write ] ---> 

* ROLE: Completely replaces or adds words to the end of an existing Text object.

=========================================
[ Show Dialogue ]
=========================================
    (Dict Key) ---> [ Dialogue ] ---> 

* ROLE: Reads a sentence from the dialogues file and displays it on screen.


--- VARIABLES & INVENTORY ---

=========================================
[ Modify / Add Variable ]
=========================================
       (Value) ---> [ Math ] ---> (Updated Variable)

* ROLE: Replaces or adds a value (or a calculation) to a Variable.

=========================================
[ Inventory Management ]
=========================================
(Add to inventory) | (Remove) | (If in inventory) | (Combine)
* ROLE: Manages the list of items owned by the player and their interactions.


--- TIME ---

=========================================
[ Wait (ms) ]
=========================================
        (Time) ---> [ Pause ] ---> (Next action)

* ROLE: Pauses before continuing the execution of the subsequent nodes.


--- AUDIO ---

=========================================
[ Play Sound / Music ]
=========================================
    (mp3 File) ---> [ Play ] ---> 

* ROLE: Plays a short sound effect (can overlap) or starts a long background audio track.


--- ANIMATIONS ---

=========================================
[ Play / Stop Animation ]
=========================================
   (Anim Name) ---> [ Play ] ---> 

* ROLE: Starts a predefined sequence of images (Sprite animation) on the object, or stops it.

=========================================
[ Glide To ]
=========================================
         (X,Y) ---> [ Movement ] ---> 
    (Duration) ---> 

* ROLE: Moves the object to new coordinates smoothly (Tween).


--- PHYSICS ---

=========================================
[ Apply Impulse / Force ]
=========================================
       (Force) ---> [ Push ] ---> 

* ROLE: Applies a force to an object subjected to the engine's terrestrial gravity.

=========================================
[ Set Velocity ]
=========================================
    (Velocity) ---> [ Impose ] ---> 

* ROLE: Imposes an instantaneous movement speed on a physics object.

=========================================
[ Ground Condition ]
=========================================
      (Object) ---> [ Grounded? ] ---> (True / False)

* ROLE: Checks if the object subjected to gravity is currently resting on a solid surface (essential to allow jumping).

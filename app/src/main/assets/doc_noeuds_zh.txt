================================================
  YOP2D 官方文档 - 蓝图 (BLUEPRINT)
================================================

本文档使用可视化格式，帮助你理解如何连接节点 (块)。
( ) = 你需要配置或作为输入连接的内容。
[ ] = 节点本身。
---> = 动作的方向 (程序的执行流)。

--- 事件 (EVENTS) ---

=========================================
[ 启动时 ]
=========================================
        (开始) ---> [ 执行 ] --->

* 作用：在场景加载到屏幕时自动且仅执行一次。
* 示例：将敌人放置在起始位置，或将玩家的初始生命值设为 100。

=========================================
[ 每一帧 ]
=========================================
        (循环) ---> [ 执行 ] --->

* 作用：在每次屏幕刷新时 (帧率) 持续执行。
* 示例：让一个物体无限自转，或实时更新分数。

=========================================
[ 点击物体时 ]
=========================================
        (目标) ---> [ 点击! ] ---> (执行)

* 作用：当玩家的手指触摸目标物体时触发。
* 示例：打开宝箱，触发按钮或开始对话。

=========================================
[ 结束点击 ]
=========================================
        (屏幕) ---> [ 松开 ] ---> (执行)

* 作用：当玩家的手指离开屏幕时 (任意位置) 触发。
* 示例：手指抬起时停止射击。

=========================================
[ 开始 / 结束拖拽 ]
=========================================
        (物体) ---> [ 拖拽 ] ---> (执行)

* 作用：当玩家开始拖动可移动物体，以及松开时触发。
* 示例：将钥匙拖拽并松开在门上以打开门。

=========================================
[ 碰撞 A/B ]
=========================================
      (物体 A) ---> [              ]
      (物体 B) ---> [ 发生碰撞!    ] ---> (执行)

* 作用：在物体 A 与物体 B 发生物理接触的确切时刻触发。
* 示例：当"玩家"触碰"金币" -> 播放声音并销毁金币。

=========================================
[ 如果物体触碰 Tag ]
=========================================
        (物体) ---> [              ]
    (Tag 文本) ---> [ 发生碰撞!    ] ---> (执行)

* 作用：当目标物体与带有指定标签 (Tag) 的任何物体发生碰撞的确切时刻触发。
* 示例：当"导弹"触碰带有"敌人"标签的物体 -> 爆炸。

=========================================
[ 进入 / 离开区域 ]
=========================================
      (物体 A) ---> [              ]
      (区域 B) ---> [ 通过       ] ---> (执行)

* 作用：当物体进入或离开定义区域时激活 (非常适合隐形触发器)。
* 示例：玩家进入"陷阱"区域 -> 地刺从地下冒出。

=========================================
[ 悬停时 / 结束悬停 ]
=========================================
        (目标) ---> [ 悬停 ] ---> (执行)

* 作用：处理手指或指针在物体上方悬停的操作，无需点击。
* 示例：悬停时高亮显示按钮。

=========================================
[ 受到冲击时 (物理) ]
=========================================
        (物体) ---> [ 冲击! ] ---> (执行)

* 作用：检测物体在开启重力的情况下反弹或撞击到固体元素。
* 示例：石头掉在地上时发出碰撞声。

=========================================
[ 当变量改变时 ]
=========================================
        (变量) ---> [ 改变 ] ---> (执行)

* 作用：持续监控一个变量。一旦其值发生改变，此节点将执行后续逻辑。
* 示例：如果生命值发生变化，更新视觉上的生命条。

=========================================
[ 本地事件 ]
=========================================
    (事件名称) ---> [ 接收 ] ---> (执行)

* 作用：一个自定义事件，你可以通过"调用本地事件"节点在远处触发它。
* 示例：将"游戏结束"逻辑分组，以便从多个地方调用。

=========================================
[ 动作点击时 (冒险) ]
=========================================
        (按钮) ---> [ 动作! ] ---> (执行)

* 作用：专门在按下界面上的虚拟“动作”按钮时触发。
* 示例：与 NPC 交谈或阅读面前的告示牌。


--- 移动 & AI (MOVEMENTS & AI) ---

=========================================
[ 持续前进 ]
=========================================
        (速度) ---> [ 前进 ] ---> 

* 作用：应用恒定速度。物体将沿其旋转角度的方向自动移动。
* 示例：直线发射的弹丸或行驶的汽车。

=========================================
[ 追逐 / 逃离物体 ]
=========================================
        (目标) ---> [ 跟随/逃离 ] ---> 

* 作用：使物体 A 自动向物体 B 移动 (或反向远离)。
* 示例：追踪导弹或跟随玩家的幽灵。

=========================================
[ 停止移动 / 停止 ]
=========================================
        (物体) ---> [ 停止 ] ---> 

* 作用：立即取消物体上所有追逐、逃离或持续前进的命令。
* 示例：当敌人被冰冻法术击中时将其冻结。


--- 空间逻辑 (SPATIAL LOGIC) ---

=========================================
[ A 与 B 之间的距离 ]
=========================================
      (物体 A) ---> [              ] ---> (真)
      (物体 B) ---> [    距离    ]
        (条件) ---> [              ] ---> (假)

* 作用：计算物体 A 和物体 B 之间的像素距离。
* 示例：检查玩家是否离得足够近可以开门。

=========================================
[ 朝向 (Look At) ]
=========================================
        (目标) ---> [ 朝向 ] ---> 

* 作用：旋转物体 A 使其面向物体 B。
* 示例：防御炮塔瞄准玩家。

=========================================
[ 最近的物体 / 随机 ]
=========================================
         (Tag) ---> [ 寻找 ] ---> (保存到变量)

* 作用：定位最近的物体或随机物体以供后续使用。
* 示例：自动瞄准最近的敌人。


--- 逻辑 & 条件 (LOGIC & CONDITIONS) ---

=========================================
[ 条件 (变量) ]
=========================================
        (变量) ---> [              ] ---> (真)
      (比较器) ---> [    条件    ]
          (值) ---> [              ] ---> (假)

* 作用：将变量的值与数字或文本进行比较。
* 示例：如果 (分数 > 10) 则 (下一关) 否则 (无)。

=========================================
[ 如果物体 A 触碰区域 B ]
=========================================
      (物体 A) ---> [              ] ---> (真)
      (区域 B) ---> [ 是否重叠?  ]
                    [              ] ---> (假)

* 作用：在确切时刻立即检查两个物体是否重叠。

=========================================
[ 双重条件 (与/或) ]
=========================================
      (条件 1) ---> [              ] ---> (真)
     (与 / 或) ---> [  双重判断? ]
      (条件 2) ---> [              ] ---> (假)

* 作用：允许同时检查两个条件。
* 示例：如果 (玩家在地面) 并且 (按下跳跃键) -> 跳跃。

=========================================
[ 如果物体可见 / 如果有 Tag ]
=========================================
        (物体) ---> [ 检查 ] ---> (真 / 假)

* 作用：检查物体是否在屏幕上，或者是否具有请求的标签 (Tag)。

=========================================
[ 调用函数 ]
=========================================
      (文件名) ---> [ 函数 ] ---> 

* 作用：执行保存在"functions"文件夹中的外部蓝图。
* 示例：创建一个可以在所有关卡中重复使用的"生成怪物"函数。

=========================================
[ 序列 (Sequence) ]
=========================================
        (输入) ---> [ 序列 ] ---> (分支 1)
                    [      ] ---> (分支 2)

* 作用：将执行分成多个分支，以构建和组织你的蓝图逻辑。

=========================================
[ 冷却时间 (Cooldown) ]
=========================================
      (持续时间) ---> [ 冷却 ] ---> (允许执行)

* 作用：在设定的时间内暂时阻止后续节点的执行。
* 示例：限制射击频率 (每发子弹之间等待 1 秒)。

=========================================
[ 其他检查... ]
=========================================
(如果摇杆激活) | (如果正在移动) | (如果按钮被按住) | (如果在屏幕外)
* 作用：根据当前状态输出 (真 / 假) 的快速测试块。


--- 场景 & HUD (SCENE & HUD) ---

=========================================
[ 更改 / 重新加载场景 ]
=========================================
    (场景名称) ---> [ 更改 ] ---> 

* 作用：加载新房间/关卡。当前场景将被自动保存。

=========================================
[ 实例化 / 关闭场景 ]
=========================================
    (场景名称) ---> [ 实例 ] ---> 

* 作用：在当前场景中加载一个预制件 (Prefab) 或元素 (如弹出窗口)。

=========================================
[ 固定摄像机 ]
=========================================
        (物体) ---> [ 跟随 ] ---> 

* 作用：将摄像机锁定在目标物体上以自动跟随它。

=========================================
[ 摄像机震动 / 弹性 ]
=========================================
        (强度) ---> [ 震动 ] ---> 

* 作用：震动屏幕或修改摄像机跟随的平滑度。
* 示例：爆炸时产生剧烈震动。


--- 外观 & 物体 (APPEARANCE & OBJECTS) ---

=========================================
[ 移动 / 推动物体 ]
=========================================
        (坐标) ---> [ 移动 ] ---> 

* 作用：将物体传送或推至新的 X 和 Y 坐标。

=========================================
[ 生成克隆 (Spawner) ]
=========================================
        (模型) ---> [ 生成 ] ---> 

* 作用：克隆请求的模型物体并使其出现。可附加到目标或固定位置 (X, Y)。

=========================================
[ 射击 ]
=========================================
        (抛射物) ---> [ 射击 ] ---> 
          (角度) --->

* 作用：立即从目标朝特定方向生成并推进一个物体。

=========================================
[ 销毁 / 按 Tag 销毁 ]
=========================================
        (物体) ---> [ 销毁 ] ---> 

* 作用：将物体或场景中带有指定标签的所有物体永久删除。

=========================================
[ 修改进度 ]
=========================================
          (值) ---> [ 进度条 ] ---> 

* 作用：更新进度条 (例如生命条) 的视觉填充。

=========================================
[ 显示模式 & 滤镜 ]
=========================================
* 作用：包含 [更改 Z-Order]、[更改图像]、[颜色滤镜]、[不透明度] 和 [混合模式] 节点，用于修改精灵 (Sprite) 的外观。

=========================================
[ 屏幕行为 ]
=========================================
* 作用：[保持在屏幕内] (隐形墙) 和 [穿透屏幕] (吃豆人效果) 节点，用于控制游戏边界。


--- 文本 & 对话 (TEXTS & DIALOGUES) ---

=========================================
[ 修改 / 追加文本 ]
=========================================
        (文本) ---> [ 写入 ] ---> 

* 作用：完全替换现有文本对象的内容或在末尾添加单词。

=========================================
[ 显示对话 ]
=========================================
      (字典键) ---> [ 对话 ] ---> 

* 作用：从对话文件中读取一个句子并显示在屏幕上。


--- 变量 & 物品栏 (VARIABLES & INVENTORY) ---

=========================================
[ 修改 / 增加变量 ]
=========================================
          (值) ---> [ 数学 ] ---> (更新后的变量)

* 作用：替换或增加变量的值 (或进行计算)。

=========================================
[ 物品栏管理 ]
=========================================
(添加到物品栏) | (移除) | (如果在物品栏中) | (组合)
* 作用：管理玩家拥有的物品列表及其交互。


--- 时间 (TIME) ---

=========================================
[ 等待 (毫秒) ]
=========================================
        (时间) ---> [ 暂停 ] ---> (下一步操作)

* 作用：在继续执行后续节点之前暂停。


--- 音频 (AUDIO) ---

=========================================
[ 播放声音 / 音乐 ]
=========================================
     (mp3 文件) ---> [ 播放 ] ---> 

* 作用：播放短促的音效 (可重叠) 或启动长的背景音频轨道。


--- 动画 (ANIMATIONS) ---

=========================================
[ 播放 / 停止动画 ]
=========================================
    (动画名称) ---> [ 播放 ] ---> 

* 作用：在物体上播放预定义的图像序列 (精灵动画) 或停止它。

=========================================
[ 滑动至 (Glide To) ]
=========================================
         (X,Y) ---> [ 移动 ] ---> 
      (持续时间) ---> 

* 作用：使物体平滑移动到新坐标 (补间动画)。


--- 物理 (PHYSICS) ---

=========================================
[ 施加冲量 / 力 ]
=========================================
          (力) ---> [ 推动 ] ---> 

* 作用：对受引擎地球重力影响的物体施加力。

=========================================
[ 设定速度 ]
=========================================
        (速度) ---> [ 设定 ] ---> 

* 作用：强制设定物理物体的瞬时移动速度。

=========================================
[ 触地条件 ]
=========================================
        (物体) ---> [ 在地面? ] ---> (真 / 假)

* 作用：检查受重力影响的物体当前是否停在固体表面上 (允许跳跃的必要条件)。

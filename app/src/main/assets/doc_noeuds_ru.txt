================================================
  ОФИЦИАЛЬНАЯ ДОКУМЕНТАЦИЯ YOP2D - BLUEPRINT
================================================

В этой документации используется визуальный формат, чтобы помочь вам понять, как соединять блоки (узлы).
( ) = То, что нужно настроить или подключить на входе.
[ ] = Сам блок.
---> = Направление действия (ход программы).

--- СОБЫТИЯ ---

=========================================
[ При запуске ]
=========================================
       (Старт) ---> [ Выполнить ] --->

* РОЛЬ: Выполняется автоматически и только один раз, как только сцена загружается на экран.
* ПРИМЕР: Поместить врагов на их стартовые позиции или установить здоровье игрока на 100.

=========================================
[ Каждый кадр ]
=========================================
        (Цикл) ---> [ Выполнить ] --->

* РОЛЬ: Выполняется непрерывно, при каждом обновлении экрана (framerate).
* ПРИМЕР: Заставить объект бесконечно вращаться вокруг своей оси или обновлять счет.

=========================================
[ При клике на объект ]
=========================================
        (Цель) ---> [ Клик! ] ---> (Выполнить)

* РОЛЬ: Срабатывает, когда палец игрока касается целевого объекта.
* ПРИМЕР: Открыть сундук, нажать кнопку или запустить диалог.

=========================================
[ Конец клика ]
=========================================
       (Экран) ---> [ Отпущено ] ---> (Выполнить)

* РОЛЬ: Срабатывает, когда игрок отпускает палец от экрана в любом месте.
* ПРИМЕР: Прекратить стрельбу, когда палец поднят.

=========================================
[ Начало / Конец перетаскивания ]
=========================================
      (Объект) ---> [ Тащить ] ---> (Выполнить)

* РОЛЬ: Срабатывает в момент, когда игрок начинает перетаскивать подвижный объект, и когда отпускает его.
* ПРИМЕР: Бросить ключ на дверь, чтобы открыть ее.

=========================================
[ Столкновение A/B ]
=========================================
    (Объект A) ---> [            ]
    (Объект B) ---> [ Удар!      ] ---> (Выполнить)

* РОЛЬ: Срабатывает в тот самый момент, когда Объект A вступает в физический контакт с Объектом B.
* ПРИМЕР: Когда "Игрок" касается "Монеты" -> Воспроизвести звук и уничтожить монету.

=========================================
[ Если объект касается Tag ]
=========================================
      (Объект) ---> [            ]
   (Текст Tag) ---> [ Удар!      ] ---> (Выполнить)

* РОЛЬ: Срабатывает в тот самый момент, когда целевой объект сталкивается с любым объектом, имеющим указанный тег (Tag).
* ПРИМЕР: Когда "Ракета" касается объекта с тегом "Враг" -> Взрыв.

=========================================
[ Вход / Выход из зоны ]
=========================================
    (Объект A) ---> [            ]
      (Зона B) ---> [ Проход     ] ---> (Выполнить)

* РОЛЬ: Активируется, когда объект входит или выходит из заданной зоны (Идеально для невидимых триггеров).
* ПРИМЕР: Игрок входит в зону "Ловушка" -> Из-под земли появляются шипы.

=========================================
[ При наведении / Конец наведения ]
=========================================
        (Цель) ---> [ Наведение ] ---> (Выполнить)

* РОЛЬ: Обрабатывает наведение пальца или курсора на объект без необходимости клика.
* ПРИМЕР: Подсветить кнопку при наведении на нее.

=========================================
[ При ударе (Физика) ]
=========================================
      (Объект) ---> [ Удар!     ] ---> (Выполнить)

* РОЛЬ: Определяет, когда объект отскакивает или ударяется о твердый элемент при включенной гравитации.
* ПРИМЕР: Издать звук камня, когда скала падает на землю.

=========================================
[ При изменении переменной ]
=========================================
  (Переменная) ---> [ Изменение ] ---> (Выполнить)

* РОЛЬ: Постоянно отслеживает Переменную. Как только ее значение меняется, этот узел запускает последовательность.
* ПРИМЕР: Если здоровье меняется, визуальная полоса здоровья обновляется.

=========================================
[ Локальное событие ]
=========================================
 (Имя события) ---> [ Получение ] ---> (Выполнить)

* РОЛЬ: Пользовательское событие, которое можно запустить удаленно с помощью узла "Вызвать локальное событие".
* ПРИМЕР: Сгруппировать логику "Game Over", чтобы вызывать ее из разных мест.

=========================================
[ При клике Действие (Приключение) ]
=========================================
      (Кнопка) ---> [ Действие! ] ---> (Выполнить)

* РОЛЬ: Срабатывает именно тогда, когда нажата виртуальная кнопка "ДЕЙСТВИЕ" в интерфейсе.
* ПРИМЕР: Поговорить с NPC или прочитать табличку перед собой.


--- ДВИЖЕНИЯ И ИИ ---

=========================================
[ Непрерывное движение ]
=========================================
    (Скорость) ---> [ Вперед ] ---> 

* РОЛЬ: Применяет постоянную скорость. Объект будет автоматически двигаться в направлении своего Угла поворота.
* ПРИМЕР: Снаряд, выпущенный по прямой, или едущая машина.

=========================================
[ Преследовать / Убегать от объекта ]
=========================================
        (Цель) ---> [ Следовать/Бежать ] ---> 

* РОЛЬ: Автоматически перемещает Объект A к Объекту B (или от него).
* ПРИМЕР: Самонаводящаяся ракета или призрак, преследующий игрока.

=========================================
[ Остановить движения / Остановка ]
=========================================
      (Объект) ---> [ Стоп ] ---> 

* РОЛЬ: Мгновенно отменяет все команды преследования, бегства или непрерывного движения для объекта.
* ПРИМЕР: Заморозить врага при попадании ледяного заклинания.


--- ПРОСТРАНСТВЕННАЯ ЛОГИКА ---

=========================================
[ Расстояние между A и B ]
=========================================
    (Объект A) ---> [            ] ---> (Истина)
    (Объект B) ---> [ Расстояние ]
     (Условие) ---> [            ] ---> (Ложь)

* РОЛЬ: Вычисляет расстояние в пикселях между Объектом A и Объектом B.
* ПРИМЕР: Проверить, достаточно ли близко игрок, чтобы открыть дверь.

=========================================
[ Повернуть к (Look At) ]
=========================================
        (Цель) ---> [ Повернуть ] ---> 

* РОЛЬ: Поворачивает Объект A так, чтобы он смотрел на Объект B.
* ПРИМЕР: Защитная турель, целящаяся в игрока.

=========================================
[ Ближайший объект / Случайный ]
=========================================
         (Tag) ---> [ Поиск ] ---> (Сохр. в переменную)

* РОЛЬ: Находит ближайший или случайный объект для последующего использования.
* ПРИМЕР: Автоматически прицелиться в ближайшего врага.


--- ЛОГИКА И УСЛОВИЯ ---

=========================================
[ Условие (Переменная) ]
=========================================
  (Переменная) ---> [            ] ---> (Истина)
    (Сравнение) ---> [  Условие   ]
    (Значение) ---> [            ] ---> (Ложь)

* РОЛЬ: Сравнивает значение Переменной с числом или текстом.
* ПРИМЕР: Если (Очки > 10) то (Следующий уровень) иначе (Ничего).

=========================================
[ Если объект A касается зоны B ]
=========================================
    (Объект A) ---> [            ] ---> (Истина)
      (Зона B) ---> [Пересечение?]
                    [            ] ---> (Ложь)

* РОЛЬ: Мгновенно проверяет, перекрываются ли два объекта в данный момент.

=========================================
[ Двойное условие (И/ИЛИ) ]
=========================================
    (Условие1) ---> [            ] ---> (Истина)
      (И / ИЛИ) ---> [ Двойное? ]
    (Условие2) ---> [            ] ---> (Ложь)

* РОЛЬ: Позволяет проверять два условия одновременно.
* ПРИМЕР: Если (Игрок на земле) И (Кнопка Прыжок нажата) -> Прыжок.

=========================================
[ Если объект видим / Если Tag ]
=========================================
      (Объект) ---> [ Проверка ] ---> (Истина / Ложь)

* РОЛЬ: Проверяет, находится ли объект на экране или есть ли у него нужный тег.

=========================================
[ Вызвать функцию ]
=========================================
  (Имя файла) ---> [ Функция ] ---> 

* РОЛЬ: Выполняет внешний Blueprint, сохраненный в папке "functions".
* ПРИМЕР: Создать функцию "SpawnMonsters", которую можно использовать на всех уровнях.

=========================================
[ Последовательность ]
=========================================
         (Вход) ---> [ Серия ] ---> (Ветвь 1)
                     [       ] ---> (Ветвь 2)

* РОЛЬ: Разделяет выполнение на несколько ветвей для структурирования и организации логики Blueprint.

=========================================
[ Cooldown (Время перезарядки) ]
=========================================
 (Длительность) ---> [ Cooldown ] ---> (Выполнение разрешено)

* РОЛЬ: Временно блокирует выполнение следующих узлов на заданное время.
* ПРИМЕР: Ограничить скорострельность (ждать 1 сек между пулями).

=========================================
[ Другие проверки... ]
=========================================
(Если джойстик активен) | (Если в движении) | (Если кнопка зажата) | (Если вне экрана)
* РОЛЬ: Блоки быстрой проверки с выходами (Истина / Ложь) в зависимости от текущего состояния.


--- СЦЕНА И HUD ---

=========================================
[ Сменить / Перезагрузить сцену ]
=========================================
   (Имя сцены) ---> [ Сменить ] ---> 

* РОЛЬ: Загружает новую комнату/уровень. Текущая сцена сохраняется автоматически.

=========================================
[ Создать экземпляр / Закрыть сцену ]
=========================================
   (Имя сцены) ---> [ Экземпляр ] ---> 

* РОЛЬ: Загружает Prefab или элемент (например, всплывающее окно) внутри текущей сцены.

=========================================
[ Зафиксировать камеру ]
=========================================
      (Объект) ---> [ Следить ] ---> 

* РОЛЬ: Привязывает камеру к целевому Объекту для автоматического следования.

=========================================
[ Тряска / Эластичность камеры ]
=========================================
         (Сила) ---> [ Тряска ] ---> 

* РОЛЬ: Трясет экран или изменяет плавность слежения камеры.
* ПРИМЕР: Сильная тряска во время взрыва.


--- ВНЕШНИЙ ВИД И ОБЪЕКТЫ ---

=========================================
[ Переместить / Толкнуть объект ]
=========================================
   (Координаты) ---> [ Двигать ] ---> 

* РОЛЬ: Телепортирует или толкает объект на новые координаты X и Y.

=========================================
[ Создать клон (Spawner) ]
=========================================
       (Модель) ---> [ Появление ] ---> 

* РОЛЬ: Клонирует запрошенную Модель и заставляет ее появиться. Доступно с привязкой к Цели или по фиксированной Позиции (X, Y).

=========================================
[ Стрелять ]
=========================================
       (Снаряд) ---> [ Выстрел ] ---> 
         (Угол) --->

* РОЛЬ: Мгновенно создает и запускает объект от цели в заданном направлении.

=========================================
[ Уничтожить / Уничтожить по Tag ]
=========================================
      (Объект) ---> [ Удалить ] ---> 

* РОЛЬ: Навсегда удаляет объект или все объекты с определенным тегом со сцены.

=========================================
[ Изменить прогресс ]
=========================================
     (Значение) ---> [ Полоса ] ---> 

* РОЛЬ: Обновляет визуальное заполнение полосы прогресса (например, полосы здоровья).

=========================================
[ Режим отображения и Фильтры ]
=========================================
* РОЛЬ: Объединяет узлы [Изменить Z-Order], [Изменить изображение], [Цветовой фильтр], [Непрозрачность] и [Режим наложения] для изменения внешнего вида спрайтов.

=========================================
[ Поведение на экране ]
=========================================
* РОЛЬ: Узлы [Удерживать на экране] (невидимая стена) и [Пересекать экран] (эффект Pac-Man) для контроля границ игры.

=========================================
[ Показать диалог ]
=========================================
 (Ключ словаря) ---> [ Диалог ] ---> 

* РОЛЬ: Читает фразу из файла диалогов и выводит ее на экран.

     (Значение) ---> [ Матем. ] ---> (Обновленная переменная)

* РОЛЬ: Заменяет или прибавляет значение (или вычисление) к Переменной.

=========================================
[ Управление инвентарем ]
=========================================

=========================================
    (Имя аним.) ---> [ Играть ] ---> 

* РОЛЬ: Запускает заданную последовательность изображений (Sprite animation) на объекте или останавливает ее.

=========================================
[ Скользить к ]
=========================================
         (X,Y) ---> [ Движение ] ---> 
 (Длительность) --->

--- ФИЗИКА ---

=========================================
[ Применить импульс / Силу ]
=========================================
         (Сила) ---> [ Толкать ] ---> 

* РОЛЬ: Придает силу объекту, подверженному земной гравитации движка.

=========================================
[ Задать скорость ]
=========================================
     (Скорость) ---> [ Задать ] ---> 

* РОЛЬ: Устанавливает мгновенную скорость движения физического объекта.

=========================================
[ Условие На Земле ]
=========================================
      (Объект) ---> [ На земле? ] ---> (Истина / Ложь)

* РОЛЬ: Проверяет, опирается ли в данный момент объект, подверженный гравитации, на твердую поверхность (необходимо для прыжка).

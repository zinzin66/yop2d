================================================
  YOP2D 公式ドキュメント - ブループリント (BLUEPRINT)
================================================

このドキュメントでは、ブロック（ノード）の接続方法を理解しやすくするために視覚的なフォーマットを使用しています。
( ) = 設定、または入力として接続する必要があるもの。
[ ] = ブロック（ノード）自体。
---> = アクションの方向（プログラムのフロー）。

--- イベント (EVENTS) ---

=========================================
[ 起動時 ]
=========================================
      (開始) ---> [ 実行 ] --->

* 役割: シーンが画面に読み込まれると、自動的に1回だけ実行されます。
* 例: 敵を開始位置に配置する、またはプレイヤーの体力を100に初期化する。

=========================================
[ 毎フレーム ]
=========================================
    (ループ) ---> [ 実行 ] --->

* 役割: 画面の更新（フレームレート）ごとに継続的に実行されます。
* 例: オブジェクトを無限に回転させる、またはスコアをリアルタイムで更新する。

=========================================
[ オブジェクトクリック時 ]
=========================================
  (ターゲット) ---> [ クリック! ] ---> (実行)

* 役割: プレイヤーの指がターゲットオブジェクトに触れたときにトリガーされます。
* 例: 宝箱を開ける、ボタンを起動する、または会話を開始する。

=========================================
[ クリック終了 ]
=========================================
      (画面) ---> [ 離した ] ---> (実行)

* 役割: プレイヤーが画面から指を離したとき（場所を問わず）にトリガーされます。
* 例: 指を離したときに射撃を停止する。

=========================================
[ ドラッグ開始 / 終了 ]
=========================================
  (オブジェクト) ---> [ ドラッグ ] ---> (実行)

* 役割: プレイヤーが移動可能なオブジェクトをドラッグし始めたとき、および離したときにトリガーされます。
* 例: 鍵をドアの上で離して開ける。

=========================================
[ 衝突 A/B ]
=========================================
(オブジェクト A) ---> [              ]
(オブジェクト B) ---> [ 衝突!        ] ---> (実行)

* 役割: オブジェクト A がオブジェクト B と物理的に接触した瞬間にトリガーされます。
* 例: 「プレイヤー」が「コイン」に触れたとき -> 音を鳴らしてコインを消去する。

=========================================
[ オブジェクトがTagに触れたら ]
=========================================
  (オブジェクト) ---> [              ]
    (Tag テキスト) ---> [ 衝突!        ] ---> (実行)

* 役割: ターゲットオブジェクトが、指定されたタグ（Tag）を持つ任意のオブジェクトと衝突した瞬間にトリガーされます。
* 例: 「ミサイル」が「敵」タグを持つオブジェクトに触れたとき -> 爆発。

=========================================
[ ゾーンへの侵入 / 退出 ]
=========================================
(オブジェクト A) ---> [              ]
    (ゾーン B) ---> [ 通過       ] ---> (実行)

* 役割: オブジェクトが定義されたゾーンに出入りしたときにアクティブになります（見えないトリガーに最適です）。
* 例: プレイヤーが「罠」ゾーンに入る -> 地面からトゲが出る。

=========================================
[ ホバー時 / ホバー終了 ]
=========================================
  (ターゲット) ---> [ ホバー ] ---> (実行)

* 役割: クリックせずに、指やポインターがオブジェクトの上を通過するのを処理します。
* 例: カーソルを合わせたときにボタンをハイライトする。

=========================================
[ 衝撃時 (物理) ]
=========================================
  (オブジェクト) ---> [ 衝撃! ] ---> (実行)

* 役割: 重力が有効な状態で、オブジェクトが跳ね返ったり固い要素にぶつかったりしたことを検出します。
* 例: 岩が地面に落ちたときに石の音を鳴らす。

=========================================
[ 変数が変わったとき ]
=========================================
      (変数) ---> [ 変更 ] ---> (実行)

* 役割: 変数を継続的に監視します。その値が変更されると、このノードはシーケンスを実行します。
* 例: 体力が変化した場合、視覚的な体力ゲージを更新する。

=========================================
[ ローカルイベント ]
=========================================
(イベント名) ---> [ 受信 ] ---> (実行)

* 役割: 「ローカルイベントを呼び出す」ノードを使用して、離れた場所からトリガーできるカスタムイベント。
* 例: 「ゲームオーバー」のロジックをグループ化して、複数の場所から呼び出せるようにする。

=========================================
[ アクションクリック時 (アドベンチャー) ]
=========================================
    (ボタン) ---> [ アクション! ] ---> (実行)

* 役割: インターフェース上の仮想「アクション」ボタンが押されたときに特別にトリガーされます。
* 例: NPCと話す、または目の前の看板を読む。


--- 移動 & AI (MOVEMENTS & AI) ---

=========================================
[ 継続的に前進 ]
=========================================
      (速度) ---> [ 前進 ] ---> 

* 役割: 一定の速度を適用します。オブジェクトは回転角度の方向に向かって自動的に移動します。
* 例: まっすぐ発射される弾丸、または走っている車。

=========================================
[ オブジェクトを追跡 / 逃走 ]
=========================================
  (ターゲット) ---> [ 追跡/逃走 ] ---> 

* 役割: オブジェクト A をオブジェクト B に向かって（または遠ざかるように）自動的に移動させます。
* 例: 追尾ミサイル、またはプレイヤーを追う幽霊。

=========================================
[ 移動を停止 / 停止 ]
=========================================
  (オブジェクト) ---> [ 停止 ] ---> 

* 役割: オブジェクトに対する追跡、逃走、または継続的な前進のコマンドを即座にキャンセルします。
* 例: 氷の呪文が当たったときに敵を凍らせる。


--- 空間ロジック (SPATIAL LOGIC) ---

=========================================
[ AとBの距離 ]
=========================================
(オブジェクト A) ---> [              ] ---> (真)
(オブジェクト B) ---> [     距離     ]
        (条件) ---> [              ] ---> (偽)

* 役割: オブジェクト A とオブジェクト B の間のピクセル距離を計算します。
* 例: プレイヤーがドアを開けるのに十分近いかどうかを確認する。

=========================================
[ 向く (Look At) ]
=========================================
  (ターゲット) ---> [ 向く ] ---> 

* 役割: オブジェクト A がオブジェクト B の方向を向くように回転させます。
* 例: プレイヤーを狙う防衛タレット。

=========================================
[ 最も近いオブジェクト / ランダム ]
=========================================
       (Tag) ---> [ 検索 ] ---> (変数に保存)

* 役割: 最も近いオブジェクトまたはランダムなオブジェクトを見つけて、後で使用できるようにします。
* 例: 最も近い敵を自動的にターゲットにする。


--- ロジック & 条件 (LOGIC & CONDITIONS) ---

=========================================
[ 条件 (変数) ]
=========================================
      (変数) ---> [              ] ---> (真)
    (比較器) ---> [     条件     ]
        (値) ---> [              ] ---> (偽)

* 役割: 変数の値を数値またはテキストと比較します。
* 例: もし (スコア > 10) なら (次のレベル) そうでなければ (何もしない)。

=========================================
[ オブジェクトAがゾーンBに触れたら ]
=========================================
(オブジェクト A) ---> [              ] ---> (真)
    (ゾーン B) ---> [重なっているか?]
                    [              ] ---> (偽)

* 役割: その瞬間に2つのオブジェクトが重なっているかどうかを即座に確認します。

=========================================
[ 二重条件 (AND/OR) ]
=========================================
      (条件 1) ---> [              ] ---> (真)
   (AND / OR) ---> [ ダブル判定?  ]
      (条件 2) ---> [              ] ---> (偽)

* 役割: 2つの条件を同時に確認できます。
* 例: もし (プレイヤーが地面にいる) かつ (ジャンプボタンが押された) -> ジャンプ。

=========================================
[ オブジェクトが見える場合 / Tagの場合 ]
=========================================
  (オブジェクト) ---> [ 確認 ] ---> (真 / 偽)

* 役割: オブジェクトが画面上にあるか、または要求されたタグ（Tag）を持っているかを確認します。

=========================================
[ 関数を呼び出す ]
=========================================
  (ファイル名) ---> [ 関数 ] ---> 

* 役割: 「functions」フォルダに保存されている外部のブループリントを実行します。
* 例: すべてのレベルで再利用可能な「モンスターをスポーン」関数を作成する。

=========================================
[ シーケンス (Sequence) ]
=========================================
      (入力) ---> [ シーケンス ] ---> (分岐 1)
                  [            ] ---> (分岐 2)

* 役割: 実行を複数の分岐に分割し、ブループリントのロジックを構造化および整理します。

=========================================
[ クールダウン (Cooldown) ]
=========================================
      (持続時間) ---> [ クールダウン ] ---> (実行許可)

* 役割: 定義された時間、後続ノードの実行を一時的にブロックします。
* 例: 連射速度を制限する（弾と弾の間に1秒待機する）。

=========================================
[ その他の確認... ]
=========================================
(ジョイスティックがアクティブな場合) | (移動中の場合) | (ボタンが長押しされている場合) | (画面外の場合)
* 役割: 現在の状態に応じた出力（真 / 偽）を持つクイックテストブロック。


--- シーン & HUD (SCENE & HUD) ---

=========================================
[ シーンの変更 / 再読み込み ]
=========================================
  (シーン名) ---> [ 変更 ] ---> 

* 役割: 新しい部屋/レベルを読み込みます。現在のシーンは自動的に保存されます。

=========================================
[ シーンのインスタンス化 / 閉じる ]
=========================================
  (シーン名) ---> [ インスタンス ] ---> 

* 役割: プレハブ（Prefab）または要素（ポップアップなど）を現在のシーン内に読み込みます。

=========================================
[ カメラを固定 ]
=========================================
  (オブジェクト) ---> [ 追従 ] ---> 

* 役割: カメラをターゲットオブジェクトにロックして、自動的に追従させます。

=========================================
[ カメラの揺れ / 弾力性 ]
=========================================
        (強度) ---> [ 揺れ ] ---> 

* 役割: 画面を揺らすか、カメラの追従の滑らかさを変更します。
* 例: 爆発時の激しい揺れ。


--- 外観 & オブジェクト (APPEARANCE & OBJECTS) ---

=========================================
[ オブジェクトを移動 / 押す ]
=========================================
      (座標) ---> [ 移動 ] ---> 

* 役割: オブジェクトを新しいXおよびY座標にテレポートさせるか、押しやります。

=========================================
[ クローンを生成 (Spawner) ]
=========================================
      (モデル) ---> [ 出現 ] ---> 

* 役割: 要求されたモデルオブジェクトを複製して出現させます。ターゲットにアタッチするか、固定位置 (X, Y) で利用可能。

=========================================
[ 撃つ ]
=========================================
    (発射物) ---> [ 撃つ ] ---> 
      (角度) --->

* 役割: 指定された方向にターゲットから即座にオブジェクトを生成し、推進させます。

=========================================
[ 破壊 / Tagで破壊 ]
=========================================
  (オブジェクト) ---> [ 破壊 ] ---> 

* 役割: オブジェクト、またはシーン内の特定のタグを持つすべてのオブジェクトを永久に削除します。

=========================================
[ 進行状況を変更 ]
=========================================
        (値) ---> [ ゲージ ] ---> 

* 役割: プログレスバー（例：体力ゲージ）の視覚的な塗りつぶしを更新します。

=========================================
[ 表示モード & フィルター ]
=========================================
* 役割: スプライト（Sprite）の外観を変更するための [Z-Orderの変更]、[画像の変更]、[カラーフィルター]、[不透明度]、[ブレンドモード] ノードのグループ。

=========================================
[ 画面の動作 ]
=========================================
* 役割: ゲームの境界を制御するための [画面内に維持]（見えない壁）および [画面を通り抜ける]（パックマン効果）ノード。


--- テキスト & 会話 (TEXTS & DIALOGUES) ---

=========================================
[ テキストを変更 / 追加 ]
=========================================
  (テキスト) ---> [ 書き込む ] ---> 

* 役割: 既存のテキストオブジェクトの内容を完全に置き換えるか、末尾に単語を追加します。

=========================================
[ 会話を表示 ]
=========================================
  (辞書キー) ---> [ 会話 ] ---> 

* 役割: ダイアログファイルから文を読み取り、画面に表示します。


--- 変数 & インベントリ (VARIABLES & INVENTORY) ---

=========================================
[ 変数を変更 / 追加 ]
=========================================
        (値) ---> [ 数学 ] ---> (更新された変数)

* 役割: 変数に値を置き換えるか、または値（または計算結果）を加算します。

=========================================
[ インベントリ管理 ]
=========================================
(インベントリに追加) | (削除) | (インベントリにある場合) | (組み合わせ)
* 役割: プレイヤーが所有するアイテムのリストとその相互作用を管理します。


--- 時間 (TIME) ---

=========================================
[ 待機 (ミリ秒) ]
=========================================
      (時間) ---> [ 一時停止 ] ---> (次のアクション)

* 役割: 後続のノードの実行を続行する前に一時停止します。


--- オーディオ (AUDIO) ---

=========================================
[ 音 / 音楽を再生 ]
=========================================
  (mp3 ファイル) ---> [ 再生 ] ---> 

* 役割: 短い効果音を再生する（重ね付け可能）か、長いバックグラウンドオーディオトラックを開始します。


--- アニメーション (ANIMATIONS) ---

=========================================
[ アニメーションを再生 / 停止 ]
=========================================
(アニメ名) ---> [ 再生 ] ---> 

* 役割: オブジェクト上の定義済み画像シーケンス（スプライトアニメーション）を開始するか、停止します。

=========================================
[ スライドする (Glide To) ]
=========================================
       (X,Y) ---> [ 移動 ] ---> 
    (持続時間) ---> 

* 役割: オブジェクトを新しい座標へスムーズに移動させます（Tween）。


--- 物理 (PHYSICS) ---

=========================================
[ インパルス / 力を加える ]
=========================================
        (力) ---> [ 押す ] ---> 

* 役割: エンジンの地球の重力にさらされているオブジェクトに力を加えます。

=========================================
[ 速度を設定 ]
=========================================
      (速度) ---> [ 設定 ] ---> 

* 役割: 物理オブジェクトの瞬間的な移動速度を強制的に設定します。

=========================================
[ 接地条件 ]
=========================================
  (オブジェクト) ---> [ 地面にいる? ] ---> (真 / 偽)

* 役割: 重力にさらされているオブジェクトが現在固い表面に乗っているかどうかを確認します（ジャンプを許可するために不可欠です）。
